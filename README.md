# Практическая работа №1.5 — карточки товаров

Сайт с четырьмя карточками керамических изделий. Сделан на **Next.js 15 + TypeScript + Tailwind CSS 4** по макету из задания.

## Запуск

Нужен Node.js 20 или новее. В терминале, находясь в папке проекта:

```bash
npm install
npm run dev
```

Затем откройте [http://localhost:3000](http://localhost:3000).

## Что сделано

- `components/ProductCard.tsx` — переиспользуемая карточка товара с изображением, названием, описанием, ценой и кнопкой.
- `data/products.ts` — массив из четырёх товаров с типами TypeScript.
- `components/ProductGrid.tsx` — отрисовка карточек через `.map()` и `key`.
- `app/page.tsx` — главная страница и кнопка коллекции.
- `app/collection/page.tsx` — страница с коллекцией.
- `app/globals.css` — первая строка `@import 'tailwindcss';`.
- `public/images/` — четыре изображения, взятые из предоставленного изображения-макета.

Кнопки «в корзину» переключают надпись на «добавлено», а «смотреть всю коллекцию» открывает `/collection`.

## Краткий отчёт

В работе я создал компонент карточки товара и передал в него данные через props. Для белых карточек и скругления использовал классы `bg-white`, `rounded-[28px]` и `p-4`. Сетку сделал с помощью `grid-cols-1`, `sm:grid-cols-2` и `lg:grid-cols-4`, чтобы карточки перестраивались на разных экранах. Класс `object-contain` помогает показать товар целиком без обрезки изображения. Кнопкам добавил `rounded-full`, `hover:bg-[#004564]` и `transition-colors` для плавного эффекта при наведении. Все товары лежат в одном массиве, а карточки выводятся через `.map()`.

## Ответы на вопросы

1. **Зачем отдельный компонент?** Чтобы использовать одну карточку для разных товаров без копирования кода.
2. **Какие классы сетки?** `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`.
3. **`object-contain` и `object-cover`?** `contain` помещает всё изображение целиком, `cover` заполняет область и может обрезать края. Для товара здесь лучше `contain`.
4. **Как задать своё скругление?** Например, `rounded-[20px]`.
5. **Зачем `key`?** Чтобы React отличал элементы списка друг от друга.
6. **Как проверить адаптивность?** Открыть F12, включить режим телефона и менять ширину окна.
7. **Что будет без `@import 'tailwindcss'`?** Утилитарные классы Tailwind перестанут применять стили.
